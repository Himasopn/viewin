# ⚡ Viewin

Quick Connect & Reach interface.

## Deploy on Vercel

1. Fork this repository
2. Go to [vercel.com](https://vercel.com)
3. Import your forked repo
4. Click Deploy
5. Done! Your instance is live.

## Features

- 🎨 Beautiful dark theme UI
- 👤 Profile configuration (username, age, gender, country)
- 💬 Custom message with character count
- 🔢 Quantity control (1-20 users per batch)
- 📊 Real-time progress tracking
- 📋 Live log stream
- 🔄 Auto server discovery
- 📱 Fully responsive design

## How It Works

1. Set your profile details
2. Write your message
3. Set quantity
4. Click Send
5. Watch live progress!

## Tech Stack

- Pure HTML, CSS, JavaScript
- No build step required
- Vercel-optimized
